# BRS · Prototipo

Prototipo navegable de Bienes Raíces Shoping (HEB). Sitio estático, sin build.

- Entrada del prototipo: `prototipo/` (abre en el login)
- Sistema de diseño (demo de componentes): raíz `index.html`

Cuentas de prueba (cualquier contraseña):
- `pyl@hebmex.com` → Permisos y licencias
- `sucursales@hebmex.com` → Inmuebles arrendados (Sucursales)

Los cambios se guardan en `sessionStorage` y se pierden al cerrar la pestaña. Para reiniciar los datos: `CLETA.reset()` en la consola.
